# OSHIMA GAME PROMPT STUDIO

団地の暮らし・交流・防災を題材に、学生やイベント運営者がWebゲームの制作指示書を作るアプリです。質問に回答し、設定を確認してから、制作AIに渡す統合Markdownを出力します。

## ローカル起動

Node.js 22 以上を使用します。依存パッケージのインストールは不要です。

```sh
npm run dev
```

ブラウザで `http://127.0.0.1:4173/` を開きます。ポートを変える場合は `npm run dev -- 4183` のように指定します。

1. 新規プロジェクトを作成するか、暮らし・防災・交流の創作プリセットを選びます。
2. 題材の根拠、参加者、ジャンル、時間、端末・操作、言語、画風、ファイル構成を指定します。
3. 設定確認からMarkdownを生成し、全文をコピーするか `.md` で保存します。

入力はブラウザの作業中のタブに保持します。ページを閉じる前に、完成したMarkdownを保存してください。

## データとテスト

- `data/presets.json` が共通プリセットの正本です。変更後に `npm run build` で配布用モジュールを更新します。
- `npm test` は配布データと正本の一致、および生成・入力検証のテストを実行します。
- `public/` が静的配信ディレクトリです。将来GitHub Pagesを構成する場合は、このディレクトリを配布対象にします。
- `examples/sorting/prompt.md` はアプリから実際にダウンロードした指示書です。`examples/sorting/index.html` をブラウザで直接開くと、仕分けゲームをオフラインで試せます。

## 地域題材の確認

1. 企画者が、創作・未確認・確認済みを区分します。確認済みの情報には出典、確認日、適用範囲を記録します。
2. 公式な生活・防災ルールや実在の設備を扱う場合は、地域の担当者が原典と照合します。照合待ちの情報は抽象化したゲーム設定に置き換えます。
3. 公開前に、住民の個人情報、文化や世代に対する決めつけ、素材の許諾、公式・公認と誤認される表示を確認します。
