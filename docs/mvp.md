# 初期実装の判断と検証

## Phase 0

入力仕様は『UR大島6丁目団地向け AIゲーム生成プロンプトアプリ 開発仕様書』v1.0 の §3・§4・§7・§8・§12 を基準にした。[旧HAP//GEN](https://github.com/odatid/happening-progen) の公開ツリー、`assets/js/generate.js`、`csv/アーケード型.csv`、`tools/build_data.js`、`tools/test.js`、`tools/verify_arcade.js` を参照した。GitHub APIのライセンス項目は未設定で、公開ツリーにライセンスファイルは見当たらなかった。既存コード、文章、データ、素材は転載せず、ブラウザ内合成と配布データ検査の考え方を独立実装した。

| 旧実装・引継ぎ資料の前提 | 初期実装の判断 |
| --- | --- |
| 単独プレイ | 1人、2人協力、親子協力。協力時は交互操作か相談方式を選択 |
| 40秒標準、最大50秒 | ジャンル・年齢・参加方式から提案。10〜3,600秒で手動変更 |
| 単一HTML、縦持ちスマートフォン | 単一HTMLと複数ファイル、PCとタッチ端末を選択 |
| 限定された画風 | 5プリセットと自由記述 |
| 旧エピソード・江戸川区ローカルデータ | 独自の創作3件。居住者の実例、個人情報、公式ルールを収録しない |
| 旧アーケード基盤14種 | A03相当のキャッチとA05相当の絵合わせに、団地題材用の仕分けパズルを追加 |

設定は `public/js/project.js` でバージョン1の内部モデル、選択肢、推奨、実行時検証を定義した。質問定義は `steps.js`、18セクションの統合テンプレートは `generate.js` に分けている。

画面の流れは「ホーム → 質問7グループ → 設定確認 → 統合Markdown」。レビューから質問に戻る操作を設けた。

## Phase 1の検証

| プリセット | 確認した組み合わせ |
| --- | --- |
| 分けて、つなごう | 仕分け・1人・単一HTML。統合版を試作入力に使用 |
| そなえの道具集め | キャッチ・2人協力・スマートフォン・複数ファイル。手動の135秒を再提案で保持 |
| あいさつ広場 | 絵合わせ・自由記述で上書き・未確認。確認済みに切り替えると出典不足を検出 |

3題材をWindowsのMicrosoft Edge 156.0.4314.58で質問から設定確認、18セクションのMarkdown出力、コピー、ダウンロードまで確認した。ビューポート幅は順に1,360px、390px、768px。`npm test` の8件はすべて合格した。

仕分け試作は、ダウンロードした `examples/sorting/prompt.md` を制作指示として同じCodex作業内で実装した。外部通信を無効にして `file://` から起動し、日英切替、誤答、タッチとキーボードでの正答、120点での完了、再試行、75秒の時間切れを確認した。別のAIセッションを使った独立再現は未実施。

## 後続フェーズ

- Phase 2で旧14基盤に対応する独自テンプレート、詳細な推奨、技術・素材の選択を拡充する。
- Phase 3で原文と編集版、永続保存・JSON入出力、総合品質検査を追加する。
- Phase 4で用途別出力・AI別アダプタ・共有URL・GitHub Pages公開を扱う。リポジトリの公開範囲、ライセンス、公開時の表示は公開準備時に決定する。
